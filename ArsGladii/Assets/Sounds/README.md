# サウンド（任意）

`<名前>.wav` / `.ogg` / `.mp3` を置くと再生されます。無ければ無音で動作します。

| 名前 | タイミング |
|---|---|
| `bgm_title` | タイトル BGM |
| `bgm_field` | フィールド BGM |
| `bgm_boss` | ボス戦 BGM |
| `swing` | 通常攻撃 |
| `skill` | ソードスキル発動 |
| `hit` / `hit_critical` | 攻撃命中 |
| `player_hit` | 被弾 |
| `dodge` | 回避 |
| `use_item` | アイテム使用 |
| `equip` | 装備変更 |
| `level_up` | レベルアップ |
| `boss_defeat` | ボス撃破 |
| `player_death` | 戦闘不能 |
| `menu_open` | メニューを開く |
