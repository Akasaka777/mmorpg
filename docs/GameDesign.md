# Ars Gladii ゲームデザイン（プロトタイプ v0.1 叩き台）

数値はすべて叩き台です。調整は各データ定義（`ItemDatabase.cpp` / `EnemyDatabase.cpp` / `Skill.cpp` / `WeaponType.cpp` / `Stats.cpp`）を書き換えるだけで反映されます。

## 1. 戦闘方式: ハイブリッド

| 操作 | 内容 |
|---|---|
| 通常攻撃（左クリック） | 移動しながら出せるリアルタイム攻撃。3段コンボ（最終段は強い）。攻撃中は移動速度 30% |
| ソードスキル（1～4） | **モーション固定**の一撃。発動中は移動不可・被弾しても怯まない（スーパーアーマー）。MP 消費＋クールダウン |
| 回避（Space） | 短距離ステップ。0.3 秒の無敵時間、クールダウン 0.8 秒 |

- 通常攻撃中にスキルを入力すると、攻撃をキャンセルしてスキルが出る（コンボの締めに使う想定）。
- 攻撃・スキル開始時、射程内の一番近い敵へ自動で向き直る。
- 敵の攻撃は地面に赤い予兆（扇形・円・直線）が出るので、回避で避けられる。

## 2. ステータス

| ステータス | 意味 |
|---|---|
| HP / MP | 体力 / スキル用の魔力 |
| ATK | 攻撃力 |
| DEF | 防御力 |
| CRI率 | クリティカル発生率 |
| CRI倍率 | クリティカル時のダメージ倍率（基本 1.5 倍） |
| 移動速度 | ワールド単位/秒（1 単位 ≒ 1cm） |

### レベルごとの基礎値（プレイヤー）

```
HP  = 200 + (Lv-1) × 30
MP  =  60 + (Lv-1) × 5
ATK =  12 + (Lv-1) × 3
DEF =   5 + (Lv-1) × 2
CRI率 5% / CRI倍率 1.5 / 移動速度 480
必要経験値(Lv→Lv+1) = 100 × Lv^1.6
```

### ダメージ式

```
ダメージ = ATK × 技倍率 × 100 / (100 + 相手のDEF)
         × 乱数(0.9～1.1)
         × クリティカル倍率（クリティカル時）
最低 1
```

DEF 100 で被ダメージ半減。減算式ではなく割合式なので、低レベルでもダメージ 0 にはならない。

## 5. 装備と個体値（IV）

- 武器・防具は**ボスからのみドロップ**（初期装備を除く）。雑魚は素材・回復/バフアイテムを落とす。
- 装備は能力ごとに 0～100 の個体値を持つ: 攻撃 / 防御 / 会心 / 体力 / 耐久

```
実ステータス = 基礎値 × (0.80 + 0.40 × IV/100)    → 基礎値の 80%～120%
最大耐久値   = 基礎耐久 × (0.70 + 0.60 × IV/100)  → 70%～130%
ランク       = 平均 IV が 85以上 S / 65以上 A / 40以上 B / それ未満 C
```

- ボスドロップは「幸運 1」: IV を 2 回振って高い方を採用（高個体値が出やすい）。
- 耐久値: 武器は攻撃が命中するたびに -1、防具は被弾のたびにランダムな1部位が -1。
  0 になると「破損」で性能 50%。修理は今後、町の鍛冶屋で実装予定（素材を消費）。

### 装備スロット
武器 / 頭 / 体 / 盾。腕・手・足は `EquipSlot` の enum に追加するだけで拡張できる。

### ボスの行動
- **薙ぎ払い**: 前方扇形（予兆 0.7 秒）
- **叩きつけ**: 周囲の円範囲（予兆 1.2 秒、1.8 倍）
- **突進**: 離れていると直線で突進（予兆 0.9 秒、1.4 倍）
- **HP 50% で激昂**: 予兆が短く、行動間隔も速くなる
- プロトタイプでは、ドロップ検証のため撃破 60 秒後に再出現する（ボスエリア外にいるとき）。
